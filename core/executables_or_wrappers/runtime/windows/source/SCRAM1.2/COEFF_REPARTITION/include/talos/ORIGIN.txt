Description
-----------
Talos is a C++ library of miscellaneous tools that make up for C++ lacks
and ease C++ programming: date and time handling, file and string
utilities, and stream/configuration parsing, with SWIG bindings for
Python. It is a required include of the COEFF_REPARTITION module.

Integration into SCRAMBoxApp
-----------------------------
This directory was converted from a git submodule to a regular directory on
2026-09-10 for portability reasons:

  - The original remote (canis01) is a private server, inaccessible to
    third-party developers.
  - Talos has not been updated since 2010 and is treated as a stable,
    static dependency.
  - A regular directory integrates cleanly with PyInstaller packaging and
    CESM build systems.

The sources are imported byte-for-byte from commit cd9634ba as exported by
"git archive"; no file has been modified.
